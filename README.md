# LWJGL Android ARM64

Automated build of [LWJGL 3.3.6](https://github.com/LWJGL/lwjgl3) for Android ARM64 (aarch64).

## What is this?

This repo provides prebuilt `liblwjgl.so` and `liblwjgl_opengl.so` for Android ARM64, compiled from LWJGL source with patches from [zomdroid-dependencies](https://github.com/liamelui/zomdroid-dependencies).

No binary files are stored in this repository. Binaries are built via GitHub Actions and published as Release assets.
